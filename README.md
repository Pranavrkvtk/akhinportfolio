# Akhin M — React Portfolio

A responsive React portfolio built with Vite and Lucide icons.

## Requirements
- Node.js (LTS recommended)
- npm (included with Node.js)

## Run locally
1. Extract this ZIP.
2. Open the extracted project folder in VS Code.
3. Open Terminal > New Terminal.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local address printed by Vite, usually `http://localhost:5173`.

## Build for deployment
```bash
npm run build
npm run preview
```

The production build is generated in the `dist` folder.
